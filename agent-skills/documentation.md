# documentation.md

## Documents

- `_documents/discovery/` - rough notes and research.
- `_documents/PRD.md` - product truth, goals, constraints.
- `_documents/epics/` - larger capabilities.
- `_documents/tz/` - implementation-ready slices.
- `_documents/TASKS.md` - current active work.
- `_documents/TESTS.md` - verification scenarios.
- `_documents/CHANGELOG.md` - concise history.
- `_documents/tasks-done/` - completed TZ/TASKS.

## Rules

- Do not implement directly from discovery.
- Do not put task lists in PRD.
- Do not leave completed work in active TASKS.
- Keep template-level docs domain-agnostic.
