# workflow.md

## Lifecycle

```text
Discovery -> PRD -> EPIC -> TZ -> Implementation -> TESTS -> CHANGELOG
```

## Rules

- Discovery is for notes and exploration, not implementation truth.
- PRD describes product truth and constraints.
- EPIC groups related outcomes.
- TZ is a small vertical slice ready for implementation.
- TASKS is the active board for the current TZ.
- TESTS lists verification scenarios.
- CHANGELOG records concise completed changes.

## TZ Shape

A TZ should include:

- goal;
- scope;
- acceptance criteria;
- verification notes.

Prefer vertical slices that produce observable behavior.
